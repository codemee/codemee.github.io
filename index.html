02 / SMALL TOOLS

我的小工具.

從工作裡的小需求，做出順手的工具。

五款工具皆支援 Windows 與 macOS；macOS 桌面版下載適用 Apple Silicon（M 系列）Mac。

FShot

截圖與標註Windows / macOS靈感來源：PicPick↓ 下載最新版本

提供日常截圖、多頁籤編輯與標註；需要高解析度圖片時，可選用虛擬 4K 螢幕擷取模式，將視窗移至虛擬螢幕重新繪製後擷取，適合製作教學與出版圖片。虛擬模式實際呈現的細節取決於目標程式的 DPI 支援。

↗

RePDF

PDF 閱讀與整理Windows / macOS靈感來源：Foxit PDF Reader↓ 下載最新版本

支援規則表達式搜尋、檔案重組與拆分，以及 OCR 文字擷取。直接擷取 PDF 內嵌圖片時，保留原始像素尺寸與透明度；重組、拆分也保留原始頁面品質。

↗

rgPDF

文件全文搜尋Windows / macOS靈感來源：Agent Ransack↓ 下載最新版本

使用規則表達式批次搜尋 PDF 與 Word 文件，支援跨行、跨頁匹配與英文行尾斷字合併。找到結果立即顯示，搭配頁面預覽與精確反白，快速定位所需內容。

↗

PicView

看圖與多圖比較Windows / macOS靈感來源：XnView↓ 下載最新版本

快速載圖、跨資料夾並排比圖，每個窗格可獨立縮放、旋轉與捲動，輕鬆看清細節與差異。操作僅影響檢視畫面，不修改原始圖片。

↗

PRKit

簡報瑞士刀Windows / macOS靈感來源：Cursor Highlighter↓ 下載最新版本

以聚光燈游標與即時按鍵顯示引導觀眾視線，搭配 Caps Lock 狀態提示，讓簡報、教學與操作示範更容易跟上。macOS 還可顯示目前的中英文輸入法。
